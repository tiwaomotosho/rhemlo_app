# rhemlo-assets v1.1

The complete visual library for **Rhemlo**:
- **Glim:** 42 poses (5 turnaround views), 13 expressions, 6 colourways, avatars, a **real cut-out rig with blink**, a side-view walk, a turnaround sequence, and rigged animation in WebP, Lottie, sprite, GIF and live-DOM formats.
- **Worlds:** 8 painted quest worlds (4 settings × day/night) with node anchors, plus 2 scenes.
- **Rewards and states:** tiers, badges, reward items, Arena props and state illustrations.
- **Brand and code:** brand files and PWA icons, fonts, icons, tokens, a motion library, a web component, an offline Lottie player, a self-testing gallery, and the concept board.

- **Start here:** [`ASSETS_GUIDE.md`](ASSETS_GUIDE.md)
- **Self-test:** open `demo/index.html` (it works from disk)
- **Quality numbers:** [`VERIFICATION.md`](VERIFICATION.md)

Install: copy this folder to `public/rhemlo-assets/`, then load `fonts/fonts.css`, `tokens/tokens.css`, `motion/rhemlo-motion.css` and `characters/glim/rhemlo-glim.js`.

- **QA evidence:** [`qa/`](qa/) (contact sheets, demo screenshots, `lottie-validation.json`).
